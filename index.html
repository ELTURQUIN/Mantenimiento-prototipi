☁ Sincronización con Supabase

Se encuentra en tu proyecto → Settings → API
Usa la Publishable key / anon public. Nunca uses service_role ni Secret key.
📖 Cómo configurar Supabase (paso a paso)

1. Entra a supabase.com y crea una cuenta gratuita.

2. Crea un nuevo proyecto (elige una contraseña, la región más cercana).

3. Espera 2 minutos hasta que se cree.

4. Ve a SQL Editor (icono de terminal en el menú izquierdo) y ejecuta este SQL para crear la tabla:

create table flotacontrol (
  id text primary key,
  entity text not null,
  data jsonb not null,
  updated_at timestamptz default now()
);
create index on flotacontrol(entity);
alter table flotacontrol disable row level security;

5. Ve a Settings → API y copia:

  • Project URL → péguelo arriba en "URL del proyecto"
  • Publishable key / anon public key → péguelo en "Anon / Public key"

6. Presiona "💾 Guardar y conectar". Este botón solo conecta: no borra ni reemplaza datos.

7. Para subir lo que tengas en este dispositivo usa "🔄 Sincronizar ahora". La sincronización combina registros y nunca borra la nube por estar vacío un dispositivo.

8. En tu celular abre la misma página y pega los mismos datos. Los cambios remotos se actualizarán automáticamente.

⚠ Importante: Como no usamos autenticación (para simplicidad), cualquiera con tu URL + anon key podría leer/escribir. Úsalo solo para uso personal y no compartas las credenciales.
